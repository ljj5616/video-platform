# 홈 API 연동

1. IntelliJ에서 백엔드를 8080 포트로 실행합니다. 백엔드 환경 변수는 기존 설정을 사용합니다.
2. frontend 폴더에서 `npm run dev`를 실행합니다. 기존 개발 서버는 프록시 설정 적용을 위해 재시작합니다.
3. 터미널의 Local 주소에서 홈 화면을 확인합니다.

Vite는 `/api` 요청을 `http://localhost:8080`으로 전달합니다. 백엔드 포트가 다르면 vite.config.ts의 proxy를 수정합니다.
배포 시에는 호스팅 서버에도 `/api`를 백엔드로 전달하는 설정이 필요합니다. Vite 개발 프록시는 dist에 포함되지 않습니다.

- GET /api/v1/videos: 검색, 카테고리 ID, 정렬, 0부터 시작하는 페이지 번호로 요청합니다.
- GET /api/v1/videos/recommendations: 비로그인 추천 영상 3개를 표시합니다.
- GET /api/v1/categories: 실제 DB의 카테고리 ID와 이름을 표시합니다.

DB에 공개 및 게시 완료 영상이 없으면 빈 목록이 표시됩니다. 임시 데이터나 DB 시드는 자동으로 추가하지 않습니다.
목록 API에는 재생 시간이 없으므로 목록 카드에는 시간을 표시하지 않습니다. 추천 API에서 반환하는 재생 시간은 표시합니다.
로그인, 업로드, 상세/재생 화면 연결과 로그인 사용자의 개인화 추천은 후속 작업입니다.

확인할 동작: 검색 제출, 카테고리 변경, 최신순/조회수순, 페이지 이동, 검색 결과 없음, 서버 중단 시 오류 및 재시도.
